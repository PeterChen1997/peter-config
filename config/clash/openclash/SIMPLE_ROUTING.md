# 家庭代理分流

更新于 2026-11-17。现网坐标、验证结果和回退记录仅在本机私有交接，agent 先读仓库根 `AGENTS.md` 和私有 `CURRENT.md`。

| 请求 | 行为 |
| --- | --- |
| 家庭内网、管理端点、中国域名/地址 | DIRECT |
| 普通外网、未知请求 | 普通出网手动选择搬瓦工、RackNerd 或隐藏的「普通自动」（两者按延迟自动选路） |
| AI 规则（包括 Gemini） | AI 出网手动选择经搬瓦工或经 RackNerd 到同一个住宅出口，默认经搬瓦工 |
| Hugging Face、Xet/LFS CDN 与 Civitai 模型域名 | 家庭模型组先走独立计量的搬瓦工连接，每个北京时间自然月 300 GB，到额后自动改走已核验的华云池 |
| Apple 上传/开发服务、GitHub/GitLab/Bitbucket | 普通出网，与其他外网共用同一手动出口 |
| 指定 PS5 主机的海外流量 | PS5 出网：仅使用已验证的机场 TCP/UDP 节点，不占普通自有 VPS 额度 |

界面显示普通、AI、模型下载三组，另有隐藏的 PS5 专用组。模型域名规则位于 AI 分类之后、普通规则之前，覆盖 `huggingface.co`、`hf.co`、`civitai.com`、`civitai.green` 以及 Civitai 专用交付主机标识。通用 GitHub 和共享存储地址仍按各自的规则处理。原生 IPv6 按用户要求保留现状。

开发服务规则位于 AI 规则之后、中国地址判断之前，指向普通组。Apple 范围为上传存储、ASC、Developer、TestFlight；Git 范围包括站点、API、代码/Release 资源和容器仓库。两份混有海外服务的历史直连列表不再被主规则引用；中国识别保留 GEOSITE/GEOIP。PS5 采用固定 DHCP 地址与非中国 IPv4 源规则；其他设备访问 PSN/Sony 仍走普通组。共享 CDN 的 CNAME 可能掩盖原始服务名，因此不依赖全网 PSN 域名例外，也不把通用 CDN 整体送入游戏组。具体地址、成员和验证记录只在私有交接。

普通出网和 AI 出网都是 `select`，在界面上手动切换，默认分别为搬瓦工和经搬瓦工的 AI 链路。隐藏的「普通自动」是 `url-test`，只在搬瓦工和 RackNerd 两个自有 VPS 之间按延迟选择，180 秒检查、100ms 容差；它不会回落到机场节点。RackNerd 链路目前从家宽不可达，保留为备用选项，切换后表现为连接失败而不是静默走别的出口。选择不持久化：重启或重载配置后回到默认值。

AI 出网的两个成员是同一个住宅出口地址（HTTP 代理）分别经搬瓦工和经 RackNerd 拨号。该出口按来源 IP 授权，且只允许一个授权 IP：同一时间只有一条链路可用，切换到「经 RackNerd」前必须在服务商处把唯一授权改到 RackNerd，切回时再改回搬瓦工；否则表现为代理拒绝（407），不会绕过。新连接使用当时的选路，已有 TCP 连接沿原路径直到重连。PS5 组使用 `url-test`，180 秒检查、100ms 容差。UDP 能力另以真实 DNS/STUN 逐节点验证。

PS5 不依赖未使用的付费 UU 插件。旧 UU 全绕行规则已禁用，PS5 的 IPv4 TCP/UDP 可进入现有代理规则；保留 STUN 防护中的主机例外，以支持游戏打洞。插件本身未购买会员或卸载，未声称已实际游玩验收。

## 配置与持久化

- 主配置为路由器 `Home-Auto.yaml`。
- `simple_routing_guard.rb` 只处理显式启用的新配置，在 OpenClash 覆写后应用本地私有拓扑。
- 私有拓扑位于路由器 `/etc/openclash/custom/simple-routing.PRIVATE.yaml`；不放入公开仓库。
- 保留浏览器 Fake-IP 恢复、IPv4 代理/DNS和既有专用 DNS policy。节点域名使用独立的上游解析，避免 DNS 自引用。
- 管理与节点 IPv4 明确直连，避免 SSH 或加密隧道被再次套入代理。
- 其他旧配置仍保留原有覆写流程，不将新拓扑强加给其他订阅。

## 扩展节点

向私有拓扑添加经过认证、加密和出口验证的节点，再加入普通组。手机导出核对共享候选身份和规则，使用 Stash 自己的延迟健康检测。家庭专用源地址规则和游戏组在手机导出时省略。

每次扩展都先备份，核心 `-t` 校验，隔离验证出口与失败行为，再热加载并更新私有交接。家庭模型组限制为 TCP。独立内核配额统计模型专用节点的双向代理包，预算服务在到额时切换选择，并先落盘保留额度，以便断电后恢复。手机导出器验证模型专用节点的身份和规则位置，手机继续使用已审阅的华云池，因为独立 Stash 连接无法经过家中路由器的计量。当前机场候选来自已实测的快照，机场剩余流量需要从服务商确认。
